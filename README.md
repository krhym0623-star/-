# 쿠폰던전: 쿠팡 가격 관측 시험

현재는 **수동 실행으로 일부 검색 결과를 관측하고 가격 기록을 누적하는 시험 단계**입니다. 사이트나 도메인은 사용하지 않습니다. 카카오톡 자동 발송은 켜져 있지 않습니다.

## 지금 직접 확인된 범위

- 쿠팡 파트너스 상품 검색 API의 `삼성 SSD 1TB` 검색은 한 번에 10행을 반환했습니다. 전체 쿠팡 상품 목록이나 실시간 전수 감시는 아닙니다.
- 실제 응답에는 `productId`가 있었지만 `vendorItemId`, `itemId`는 없었습니다. 같은 상품 ID의 검색 결과가 두 행이고 배송 표시가 달랐던 사례가 있습니다. 상품 ID만으로 옵션별 가격을 확정하지 않습니다.
- 중복 상품 ID는 관측 기록에는 남기되 가격 비교와 후보 평가에서는 제외합니다.

## 수동 관측 실행

1. 저장소의 **Actions** → **가격 이력 1회 누적 시험** → **Run workflow**를 누릅니다.
2. 처음에는 기본 검색어 `삼성 SSD 1TB`를 유지합니다. 한 번 실행할 때 검색 API를 한 번 호출합니다. 임의로 반복 실행하거나 검색어를 대량으로 늘리지 마세요.
3. 성공한 실행의 **상품 검색 한 번과 이력 누적** 로그에서 `rows`, `ambiguousRows`, `observations`, `queued`를 확인합니다.
4. 실행 페이지의 **Artifacts**에서 `price-history`를 내려받으면 `state.json`에 관측 이력과 `reviewQueue`가 있습니다. 다음 수동 실행은 가장 최근의 이 아티팩트를 복원하고 새 관측을 덧붙입니다.

이 아티팩트는 **30일 후 만료**됩니다. 장기 데이터베이스가 아니므로 만료 전에 별도 저장소로 옮겨야 합니다. 만료되거나 삭제되면 다음 실행은 새 기록부터 시작합니다. 현재 자동 일정은 없습니다.

## 후보 판정의 한계

같은 검색어와 로켓배송 표시로 하루 이상에 걸쳐 이전 관측이 세 번 이상 쌓인 경우, 이전 가격의 중앙값보다 15% 이상 낮고 이전 최저 관측 가격보다 낮으면 **사람이 확인할 후보**로 한 번만 기록합니다. 판매 옵션의 안정적인 ID가 없으므로 이를 검증된 핫딜·역대 최저가·가격 오류로 표시하거나 자동 전송하지 않습니다. `isRocket` 하나로 해외로켓배송과 판매자로켓배송을 분리할 수도 없습니다.

## API 키

저장소 **Settings** → **Secrets and variables** → **Actions**에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`를 등록합니다. 코드, README, 이슈, 채팅에 값 자체를 적지 마세요. 쿠팡 판매자 Open API 키와 파트너스 키는 다릅니다.

## 다음 단계

1. 쿠팡 파트너스 계정의 허용 API, 호출 한도, 제휴·광고 문구 규칙을 확인합니다.
2. 24시간 동안 작은 범위로 관측만 실행해 결과 누락과 중복률을 측정합니다.
3. 만료되지 않는 데이터베이스와 사람이 검토할 화면 또는 파일을 연결합니다.
4. 잘못된 후보 비율을 확인한 뒤 알림 방식을 결정합니다. 일반 카카오톡 단체방에 공식 API로 임의 자동 게시하는 기능은 전제하지 않습니다.

코드는 Node.js 22에서 `node --test`로 API 키 없이 검사할 수 있습니다. API 오류가 나면 자동으로 재시도하지 않습니다.
