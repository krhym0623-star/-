# 쿠폰던전: 쿠팡 가격 관측 시험

현재는 **일부 검색 결과의 가격을 누적하는 작은 관측 시험**입니다. 사이트와 카카오톡 자동 발송은 사용하지 않습니다.

## 확인된 범위

- 쿠팡 파트너스 API의 `삼성 SSD 1TB` 검색 결과는 한 번에 10행이었습니다. 쿠팡 전체 상품이나 실시간 전수 감시는 아닙니다.
- `productId`는 있었지만 `vendorItemId`와 `itemId`는 없었습니다. 같은 ID에 서로 다른 배송 표시가 나온 경우는 원본 기록만 남기고 가격 평가에서 제외합니다.

## 실행과 결과 확인

1. **Actions** → **가격 이력 1회 누적 시험** → **Run workflow**에서 기본 검색어를 유지합니다. 성공 실행당 검색 API를 한 번 호출합니다.
2. 저장된 기록의 마지막 성공 관측에서 **1시간 이상** 지나야 하며, 최근 24시간 성공 관측이 **8회 미만**이어야 합니다. 코드는 이를 API 요청 전에 검사합니다. 계정의 공식 호출 한도는 별도 확인이 필요합니다.
3. 실행 로그의 `rows`, `ambiguousRows`, `observations`, `queued`를 확인합니다. **Artifacts**의 `price-history` 압축파일에 `state.json`이 있고 `runs`, `observations`, `reviewQueue`가 저장됩니다. 다음 실행은 가장 최근 기록을 복원합니다.
4. 아티팩트는 **30일 후 만료**됩니다. 삭제·만료되면 이력과 호출 제한 계산도 초기화됩니다. 영구 데이터베이스가 아닙니다.

GitHub Actions 자체의 상시 일정은 없습니다. 별도의 관측 예약은 **2026년 10월 1일 23:45부터 10월 2일 19:45까지(한국 시간) 4시간 간격, 최대 6회**로 설정됐습니다. 매회 실행 전 기록을 확인하며 실패 시 자동 재시도하지 않습니다.

## 후보 판정의 한계

하루 이상에 걸쳐 이전 관측이 3회 이상 쌓이고 중앙값보다 15% 이상 낮으며 이전 최저 관측보다 낮을 때 **사람이 검토할 후보**만 남깁니다. 판매 옵션 ID가 없어서 검증된 핫딜·역대 최저가·가격 오류로 확정하거나 자동 발송하지 않습니다. `isRocket`만으로 해외로켓배송과 판매자로켓배송을 나눌 수 없습니다.

## API 키

**Settings** → **Secrets and variables** → **Actions**에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`를 둡니다. 키 값은 코드·README·이슈·채팅에 적지 마세요. 파트너스 API와 판매자 Open API는 다릅니다.

## 다음 단계

계정의 허용 API·호출 한도·제휴 문구 규칙을 확인한 뒤, 24시간 관측의 중복률·재등장률·가격 변동을 평가합니다. 이후 영구 데이터베이스와 수동 검토 절차를 만들고 알림 방식을 결정합니다. 일반 카카오톡 단체방의 임의 자동 게시를 전제하지 않습니다.

Node.js 22의 `node --test`로 API 키 없이 검사할 수 있습니다.
