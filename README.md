# 쿠폰던전: 쿠팡 가격 관측 시험

현재는 **일부 검색 결과의 가격을 수동으로 관측해 이력을 누적하는 시험 단계**입니다. 사이트·도메인과 카카오톡 자동 발송은 사용하지 않습니다.

## 확인된 범위

- 쿠팡 파트너스 상품 검색 API에서 `삼성 SSD 1TB`는 요청당 10행을 반환했습니다. 쿠팡 전체 상품이나 실시간 전수 감시는 아닙니다.
- 실제 응답에는 `productId`가 있지만 `vendorItemId`, `itemId`는 없었습니다. 같은 ID에 배송 표시가 다른 두 행이 나와 옵션별 가격을 확정할 수 없습니다. 중복 ID는 기록만 하고 가격 평가에서 제외합니다.

## 수동 관측 실행

1. 저장소의 **Actions** → **가격 이력 1회 누적 시험** → **Run workflow**를 누릅니다. 검색어는 우선 `삼성 SSD 1TB`를 유지합니다.
2. 마지막 성공 관측에서 **최소 1시간**이 지난 뒤 실행합니다. 코드는 저장된 이력을 보고 1시간 미만 또는 최근 24시간 8회 이상이면 **API 요청 전에 중단**합니다. 각 성공 실행은 검색 API를 한 번 호출합니다. 계정의 공식 호출 한도는 별도로 확인해야 합니다.
3. 성공 실행의 **상품 검색 한 번과 이력 누적** 로그에서 `rows`, `ambiguousRows`, `observations`, `queued`를 확인합니다. 0행도 실행 기록 `runs`에 남습니다.
4. 실행 페이지 **Artifacts**의 `price-history`를 내려받으면 `state.json`에 `runs`, `observations`, `reviewQueue`가 있습니다. 다음 실행은 가장 최근 아티팩트를 복원합니다. 이 기록을 지우거나 만료시키면 제한 계산도 새로 시작하므로 보관에 주의하세요.

아티팩트는 **30일 후 만료**됩니다. 장기 데이터베이스가 아닙니다. 현재 자동 실행 일정은 없으며 연속 실행 실패는 호출 제한이 작동한다는 뜻일 수 있습니다. API 실패는 자동 재시도하지 않습니다.

## 후보 판정의 한계

같은 검색어와 로켓배송 표시로 하루 이상에 걸쳐 이전 관측이 세 번 이상 있고, 이전 가격 중앙값보다 15% 이상 낮으며 이전 최저 관측보다 낮으면 **사람이 확인할 후보**만 남깁니다. 옵션 ID가 없으므로 검증된 핫딜·역대 최저가·가격 오류로 표시하거나 자동 발송하지 않습니다. `isRocket`만으로 해외로켓배송과 판매자로켓배송을 구분할 수도 없습니다.

## API 키

저장소 **Settings** → **Secrets and variables** → **Actions**에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`를 등록합니다. 키 값은 코드·README·이슈·채팅에 적지 마세요. 쿠팡 판매자 Open API와 파트너스 API 키는 다릅니다.

## 다음 단계

1. 계정의 허용 API, 호출 한도, 제휴·광고 문구 규칙을 확인합니다.
2. 같은 검색어로 24시간 작은 범위의 관측을 이어가며 중복률·상품 재등장률·가격 변동을 측정합니다.
3. 영구 데이터베이스와 수동 검토 화면을 만들고, 잘못된 후보 비율을 검증한 뒤 알림 방식을 결정합니다. 일반 카카오톡 단체방에 공식 API로 임의 게시하는 기능은 전제하지 않습니다.

Node.js 22에서 `node --test`로 API 키 없이 검사할 수 있습니다.
