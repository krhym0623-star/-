# 쿠폰던전: 쿠팡 핫딜 알림 준비

현재는 **1단계: 쿠팡 파트너스 링크 연결 시험**입니다. 사이트 배포나 도메인은 필요하지 않습니다. 상품 가격 감시, 역대 최저가 판정, 카카오톡 전송은 아직 켜져 있지 않습니다.

## 한 번만 설정하기

1. 저장소 상단 **Settings** → **Secrets and variables** → **Actions**로 갑니다.
2. **New repository secret**을 눌러 `COUPANG_ACCESS_KEY`를 만들고, 이전에 발급받은 Access Key 값을 붙여 넣습니다.
3. 같은 방법으로 `COUPANG_SECRET_KEY`를 만들고 Secret Key 값을 넣습니다.
4. 키는 README, 코드, 이슈, 채팅에 쓰지 마세요. GitHub가 저장된 Secret의 원래 값을 다시 표시하지 않는 것은 정상입니다.

## 첫 실행

1. **Actions** → **파트너스 링크 시험** → **Run workflow**를 누릅니다.
2. `coupang_url`은 기본값 그대로 두고 **Run workflow**를 누릅니다. 기본값은 쿠팡 검색 페이지이며 실제 상품 판매 링크가 아닙니다.
3. 실행 기록의 **쿠팡 링크 한 건 변환** 단계에서 `파트너스 링크:`를 확인합니다. 오류라면 키가 파트너스 API에 사용 가능한지와 입력값의 공백을 확인하세요. 로그에는 키와 전체 API 응답을 출력하지 않습니다.

키를 등록하기 전에는 실행하지 마세요. GitHub Actions는 수동 실행만 설정했습니다. `COUPANG_ACCESS_KEY`와 `COUPANG_SECRET_KEY`는 **쿠팡 파트너스**에서 발급받은 값이어야 합니다. 쿠팡 판매자 Open API 키와는 다릅니다.

## 앞으로 만들 순서

1. 파트너스 계정에서 허용된 상품 조회 API와 호출 한도, 배송 구분 필드를 확인합니다.
2. 승인된 검색 범위의 일부 상품을 주기적으로 조회하고, 상품 ID와 옵션별 관측 가격을 저장합니다. 조회 결과만으로 쿠팡의 **전 상품 실시간 가격**을 보장할 수 없습니다.
3. 관측 기록이 쌓이면 가격 하락률을 계산합니다. `역대최저가`는 우리 기록의 최저가라고 표시하고, `가격오류 의심`은 검토 대상으로만 다룹니다.
4. 후보를 사람이 확인한 뒤 파트너스 링크와 광고 표시 문구를 붙여 공유합니다. 일반 카카오톡 단체방에 API로 자동 게시하는 기능은 여기서 약속하지 않습니다.

## 개발 메모

Node.js 20 이상, 외부 패키지 없음. `node --test`로 키 없이 단위 검사를 실행할 수 있습니다. 링크 변환 요청은 한 번의 POST이며 자동 재시도를 하지 않습니다. 자세한 API 권한과 현재 제한은 쿠팡 파트너스 대시보드에서 확인하세요.
